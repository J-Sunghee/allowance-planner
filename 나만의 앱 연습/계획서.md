# 한 달 용돈 플래너 계획서 (PRD)

본 계획서는 `AGENTS.md`의 규칙에 따라 작성되었으며, 사용자의 선택을 바탕으로 구성되었습니다.

---

## 1. 입력값 (사용자가 처음 넣는 값)
- **입력 항목**:
  1. 이번 달 총 용돈 금액 (원 단위)
  2. 시작 날짜 (기본값: 오늘 날짜)
  3. 플래너 사용 기간 (기본값: 30일)
- **완료 기준**:
  - 총 용돈 금액과 시작 날짜를 입력하고 `[플래너 시작하기]` 버튼을 누르면 초기 설정이 저장되고 메인 플래너 화면으로 이동된다.
- **판단 규칙**:
  - 만약 용돈 금액에 빈칸, 0원 이하, 또는 숫자가 아닌 문자를 입력하면 `"올바른 용돈 금액을 입력해 주세요"` 경고를 띄우고 화면을 이동하지 않는다.

---

## 2. 초안 생성 (앱이 먼저 만들어 주는 계획)
- **자동 계산 항목**:
  - 하루 권장 지출 예산 = (남은 총 용돈) ÷ (남은 일수)
- **완료 기준**:
  - 초기 설정이 끝나 메인 화면에 진입하면, 자동으로 하루 권장 예산이 계산되어 `오늘 쓸 수 있는 돈` 카드에 즉시 표시된다.
- **판단 규칙**:
  - 만약 총 용돈 300,000원에 기간이 30일이면, 첫날 하루 예산은 10,000원으로 계산하여 표시한다.

---

## 3. 실행 기록 (사용자가 날마다 남기는 것)
- **기록 항목**:
  1. 지출 금액 (원)
  2. 사용처 / 메모 (예: 점심 식사, 편의점 등)
  3. 카테고리 선택 (식비, 카페/간식, 교통, 쇼핑, 문화/취미, 기타)
- **완료 기준**:
  - 지출 금액, 내용, 카테고리를 입력하고 `[지출 등록]` 버튼을 누르면 오늘의 지출 목록 맨 위에 추가된다.
  - 지출 목록의 `[삭제]` 버튼을 누르면 해당 지출이 즉시 목록에서 제거된다.
- **판단 규칙**:
  - 만약 지출 금액에 0원 이하이거나 숫자가 아닌 값을 입력하면 `"지출 금액을 올바르게 입력해 주세요"` 안내를 띄우고 저장하지 않는다.
  - 만약 지출을 삭제하면 당일 사용 금액 합계가 줄어들고 `오늘 쓸 수 있는 돈`과 `남은 총 용돈`이 다시 복구 계산된다.

---

## 4. 모니터링 (한눈에 보여 줄 것)
- **메인 화면 표시 항목**:
  1. **오늘 쓸 수 있는 돈**: (오늘의 목표 예산) - (오늘 사용한 금액 합계)
  2. **남은 총 용돈**: (이번 달 총 용돈) - (이번 달 누적 총 지출액)
  3. **남은 기간**: (총 기간) - (경과 일수) (예: D-29, 30일 중 1일차)
  4. **오늘의 지출 내역 목록**: 등록된 지출 항목들의 시간/카테고리/내용/금액
- **완료 기준**:
  - 지출을 등록하거나 삭제할 때마다 `오늘 쓸 수 있는 돈`과 `남은 총 용돈` 수치가 새로고침 없이 즉각 갱신된다.
- **판단 규칙**:
  - 만약 `오늘 쓸 수 있는 돈`이 0원 이상이면 숫자를 초록색(안전)으로 표시한다.
  - 만약 `오늘 쓸 수 있는 돈`이 0원 미만(초과 지출)이면 숫자를 빨간색으로 표시하고 `[오늘 예산 초과!]` 뱃지를 표시한다.
  - 만약 `남은 총 용돈`이 0원 미만이 되면 상단에 `"이번 달 총 용돈을 모두 소진했습니다!"` 경고 알림창을 붉은색으로 띄운다.
  - 만약 `남은 날`이 0일이 되면 `"이번 달 플래너 기간이 종료되었습니다"` 문구를 표시하고 지출 입력창을 비활성화한다.

---

## 5. 재조율 (계획대로 안 됐을 때 다시 맞추는 규칙)
- **재조율 방식**:
  - 하루가 지나 다음 날이 되면, 어제 남은 돈이나 초과 지출한 돈이 전체 잔여 용돈에 자동 반영되어 `(남은 총 용돈) ÷ (남은 일수)` 공식으로 오늘의 새 예산이 산정된다.
- **완료 기준**:
  - 상단의 `[다음 날로 이동]` 버튼을 누르면 앱 내부의 가상 날짜가 하루 증가하고, 새로운 날짜의 `오늘 쓸 수 있는 돈`이 남은 일수에 맞춰 다시 계산된다.
- **판단 규칙**:
  - 만약 어제 돈을 아껴서 남은 총 용돈이 넉넉해졌다면 다음 날 `오늘 쓸 수 있는 돈`은 이전 날 권장 예산보다 증가한다.
  - 만약 어제 예산을 초과해서 썼다면 다음 날 `오늘 쓸 수 있는 돈`은 남은 일수만큼 나누어 차감되어 이전 날보다 감소한다.
  - 만약 남은 총 용돈이 0원 이하이면 다음 날 `오늘 쓸 수 있는 돈`은 0원으로 고정된다.

---

## 추가로 확정한 규칙
1. 단일 파일 웹앱: 모든 HTML, CSS, JavaScript 코드는 `나만의 앱 연습/index.html` 단일 파일에 작성한다.
2. 외부 의존성 없음: 프레임워크, npm, 외부 CDN, 서버, 외부 AI API 없이 순수 바닐라 JS/CSS로 구동한다.
3. 데이터 저장: 모든 데이터는 브라우저 `localStorage`에 저장하며 접두사 `allowance_planner_`를 사용한다.
4. 모바일 반응형: 가로 폭 360px 모바일 화면 기준으로 가로 스크롤 없이 모든 텍스트와 버튼이 깔끔하게 표시된다.
5. 화폐 표기: 모든 금액은 한국 원화 포맷(예: `12,000원`)으로 세 자리마다 콤마를 표시한다.
6. 필수 테스트 버튼 상시 배치:
   - `[다음 날로 이동]`: 가상 날짜를 하루 넘겨 재조율 계산을 검증할 수 있는 버튼.
   - `[처음부터 다시]`: `confirm` 확인 창을 띄운 뒤 모든 저장 데이터를 초기화하고 첫 입력 화면으로 리셋하는 버튼.
